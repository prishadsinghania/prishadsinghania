# Hey, I'm Prisha! 👋

I like figuring things out. Sometimes that's untangling a dataset that looks like it survived a natural disaster. Sometimes it's automating a report because doing the same thing manually twice feels like a personal defeat. And sometimes it's spending an entire weekend building something that nobody asked for.

I recently graduated from the University of Illinois Urbana-Champaign with an MS in Information Management, and I work in cybersecurity analytics at RedLegg.
